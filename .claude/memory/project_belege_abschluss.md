Anlass 2026-10-07: "Abgeschlossen"-Liste enthält Aufträge ohne Rechnung; Buchhaltungsexport zählt Aufträge nach Bestelldatum (auch unbezahlt/ungeliefert) als Umsatz.

**Entscheidungen Jacky (2026-10-07):**
- MEALANA ist eine KG → Soll-Versteuerung, USt entsteht mit Rechnung
- Teilrechnung pro Lieferung (nur versendete Artikel, ausständige angeführt), Rechnung per Mail
- Gutschein-Bestellung bekommt Beleg (Rechnung 0 %)
- Abgeschlossen nur wenn voll geliefert + bezahlt (+ Beleg); bei Retoure wieder offen bis GS/Erstattung erledigt
- Bon = Rechnung (gleichgestellt); Online bestellt + an Kasse bezahlt → Bon ist Beleg, A4-Bon an Abholmail; NIE Bon UND Rechnung für dieselbe Ware
- Umsatz/Buchhaltung NUR aus Bon, Gutschrift, Rechnung, Gutschein — Aufträge nur "erwarteter Umsatz"
- Belege-Spalte mit Icons in Auftragsliste, Mehrfach-Belege (Teillieferungen) als Zähler-Badge

**Ist-Befunde 2026-10-07:**
- Packplatz erstellt Rechnung nur bei bezahlt + keine Teillieferung + Kunde hat E-Mail (abschliessen.php)
- "abgeschlossen" an ~6 Stellen ohne Beleg-Prüfung gesetzt (Packplatz, bucheZahlung, bearbeiten, Shop-Sync completed, Kasse Abholung, Gutschein-only)
- Bezahlte Abholung an Kasse ohne Bon ("nurAbschliessen") → weder Bon noch Rechnung
- Buchhaltung: Aufträge kanal manuell/woocommerce mit Abholung+Bon an Kasse vermutlich DOPPELT (Auftrag-Block + Bon-Block)
- Gutschriften haben keine eigene Tabelle (nur PDF + auftrag_dokumente) → Beträge nicht auswertbar
